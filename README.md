## Overview

This project helps users manage leads efficiently through a clean dashboard interface. Users can add, search, and manage lead information with a responsive frontend connected to a PostgreSQL database.

# Lead Management System

A full stack Lead Management application using:

- React.js
- Node.js
- Express.js
- PostgreSQL

## Features

- Add new leads
- View all leads in a dashboard
- Search leads instantly
- Lead status tracking
- Responsive modern UI
- REST API integration
- PostgreSQL database connectivity


## Tech Stack
Frontend: React + Vite  + CSS
Backend: Node.js + Express  
Database: PostgreSQL
